# 本机内存治理与安全测试（2026-11-03）

## 目标与实测问题

保留本地模拟付款/退款，不接入真实资金渠道。原本16GB系统仅余354MB物理内存和1155MB提交额度，WSL私有提交约8133MB；全栈同时执行大范围测试导致服务退出。堆上限不是Java进程全部内存，元空间、线程、直接缓冲区及代码缓存也占用内存。

## 本次调整

1. 用户确认无其他WSL工作后，停止本项目进程和五个容器，再重启WSL/Docker；没有删除卷或重新初始化数据库。新建用户目录.wslconfig：memory=5GB、processors=2、swap=2GB、experimental.autoMemoryReclaim=gradual。Docker实测MemTotal=5158051840字节。Windows页面文件未修改。WSL配置作用于本用户WSL2，修改与重启机制参考 https://learn.microsoft.com/windows/wsl/wsl-config 。
2. Get-LocalServicePlan：User/Product/Order/Search最大堆256MB，其余六个192MB，总2176MB（原2816MB）。所有本地Java初始堆32MB，SerialGC，2个逻辑处理器，单层编译，代码缓存48MB，直接内存64MB，线程栈512KB。只用于本地小数据量；生产配置未更改。
3. 启动前要求物理余量1536MB、提交余量7168MB；每个服务启动前至少1024MB/2048MB。首次8GB提交额度门槛曾正常拦住启动；结合较低堆预算调整为7GB。阈值是预留门槛，不是系统资源永久保证。
4. 新增test-local-memory-safe.ps1：核验归属后暂停启动器登记进程，保留Docker，Python/前端/Maven顺序测试，Maven按模块独立JVM，测试阶段开始前至少1536MB物理/3072MB提交余量。若原来在运行，finally调用启动器自动恢复。未登记程序不会被杀掉。测试不进行真实支付、不重置用户数据。恢复失败时保留restore.log和resume-processes.json，退出非零，不冒充已恢复。
5. 新增watch-local-memory.ps1：有界只读抽样，物理余量低于1GB或提交余量低于2GB时返回非零。抽样数据不是性能压测或无限期承诺。

## 日常使用

在内层项目目录 E:/Simlect-AI-Mall-main/Simlect-AI-Mall-main 的PowerShell运行：

```powershell
# 演示：启动Java+AI+商城，已有服务时不要重复启动
.\start-local.cmd -WebOnly

# 快速回归：自动暂停已登记项目服务，测试后恢复

# 完整定向回归：同样暂停服务后按模块执行，耗时更长

# 约一分钟内存观察
powershell -NoProfile -ExecutionPolicy Bypass -File .\deploy\watch-local-memory.ps1 -OutputPath .\logs\memory-now.json
```

## 限制与恢复

当前方案为本机演示与回归分时运行，不保证全栈、全量构建和任意外部程序同时运行仍有充足内存。若保护拒绝继续，不要反复运行或调低阈值绕过；关闭不必要程序后重试。若进程在测试时被强行关闭、系统重启或断电，finally无法保证执行，需检查result.json和登记状态后恢复。

真实资金退款不再作为当前交付目标；生产支付接入、真实物流和向量检索仍不纳入本地验收通过范围。

## 恢复脚本兼容性补充

在真实暂停/恢复演练中修复两项PowerShell5.1问题：

- Docker正常进度写入stderr不能按异常判定；公共Invoke-LocalLoggedCommand以原生命令退出码决定成败，并用临时Node脚本验证stderr+exit0通过、stderr+exit7失败。
- 后台服务继承输出管道可能令外层调用在启动器退出后仍阻塞。恢复改用Start-Process分离stdout/stderr文件，仅对启动器PID调用WaitForExit(timeout)，不等待后台服务生命周期。

测试入口新增-ResumeStack，供已暂停状态下显式恢复；日常从运行态测试不需要此参数。首次两次演练失败记录保留，不能算成成功。旧“当前恢复阻塞”段落为历史记录，最终状态以本文末尾验收更新为准。

修改文件汇总：deploy/local-stack-common.ps1（预算/原生命令日志/Java参数）、deploy/start-local.ps1（启动前及逐服务内存门槛）、deploy/repair-local-services.ps1（单服务恢复同样检查余量）、deploy/test-local-memory-safe.ps1（分时测试和自动恢复）、deploy/watch-local-memory.ps1（有界内存采样）、deploy/test-local-launcher.ps1（低内存拒绝/原生stderr及原有归属回归）。未修改业务代码、真实资金配置或Windows页面文件。
