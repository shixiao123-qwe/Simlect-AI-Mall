# 50件公开真实商品样本：导入、测试与数据边界

## 已添加什么

商品资料与图片采用Amazon Berkeley Objects（ABO），来源与许可已核对官方页面：https://amazon-berkeley-objects.s3.amazonaws.com/index.html 。CC BY 4.0许可正文、署名和变更说明位于data/public-catalog/。

本批50件：家居用品10、灯具10、办公用品10、厨具10、手机壳6、运动用品4；不是50件耳机。使用官方中文名称（如有）或英文名称，中文品类标签由适配器添加。原始商品记录及ASIN保存在products.json，不用大模型编造名称或技术参数。

50张本地图片合计344442字节（约336KB），使用官方256像素版本，没有下载3GB完整图片归档。只读取两个约5MB元数据分片和一个约6MB图片索引，逐行处理；不存在加载全量商品库或海量评论。下载缓存用于断点复用。

## 真实字段与模拟字段

| 字段 | 处理 |
|---|---|
| 商品原始名称、品牌、颜色、材质、型号、描述、图片 | 从来源提取，缺失不补造；公开前保留署名 |
| 中文品类标签、展示前缀 | 本项目添加，名称标记[公开样本] |
| 商品价格 | ABO无可用售价；本项目生成明确的人民币测试价，不是美元换算或真实报价 |
| 库存 | 测试库存，含零库存，用于业务筛选；不是来源真实可售库存 |
| SKU | 每商品一个默认测试SKU，真实属性挂接到该SKU；不是来源真实规格组合 |
| 成色、低延迟、续航等未提供参数 | 不生成、不推测；严格要求未知属性时应该拒绝匹配 |
| 订单、支付、退款及用户 | 不从公开数据导入；继续由本地业务流程生成 |

商品详情描述包含来源、许可及价格/库存/SKU为测试值的说明。公开数据不代表当前仍可购买的真实在售商品，页面也不代表Amazon认可本项目。

## 实际数据映射

- sys_category：A9100公开样本父分类及六个子分类。
- product_info：ABO+来源10位商品ID，共13位，符合项目varchar(15)。
- sys_product_property / product_property_value：来源真实属性及默认测试规格。
- product_sku：与属性ID组合对应的MD5键，价格为本地测试值。
- simlect_stock.sku_stock：相同productId+skuHash，单独存放测试库存。

SQL仅INSERT...WHERE NOT EXISTS，使用事务；不更新原商品、不删除数据、不触及订单/支付表。重复导入不会重置库存。新增行之后仅重启Product刷新启动布隆过滤器，否则详情可能被误判不存在；然后调用Search的内部同步接口更新ES。

## 如何使用

已经完成本机导入，不需要再次执行。打开商城 http://127.0.0.1:6001/ ，刷新后搜索“公开样本”，或搜索“厨具”“办公用品”“手机壳”。点击商品查看图片、属性和数据说明。智能客服可尝试“推荐300元以内的厨具”，再对比展示列表中的两款。

若之后需要重新导入，在项目内层目录执行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\deploy\import-public-catalog.ps1 -SyncSearch
```

该命令会短暂重启Product，不会重启整套项目。原6款DEMOAI商品和已有3笔订单保留。50件样本的模拟库存使用过程中会改变，不要为了跑分重置它。

需要重新采集时运行deploy/prepare-public-catalog.py，并通过--upload-root传入deploy/.env.local中的PROJECT_FOLDER。准备器不读取或修改数据库；导入器校验SQL的SHA256及本地图片存在后才执行。正常演示不需要重新下载。

## 内存与限制

未增加Docker或Java内存上限。最后一次读数：物理余量2580MB、系统提交余量1312MB，提交额度低于安全测试门槛；本轮没有运行Maven或全量回归。该读数受整个系统及WSL影响，不能仅凭50件数据推断其增量内存。后续回归继续使用deploy/test-local-memory-safe.ps1先暂停服务，不要在全栈运行时开启另一套构建。

仍未验证真实物流、真实资金、全品类语义识别和压力性能；本批数据的用途是让本地商品展示及导购更贴近真实资料。
